Game Packs

.nori 하나면
게임 하나

게임팩은 코드, 에셋, 메타데이터를 하나로 묶은 파일입니다. 설치 과정이 없고, 삭제도 파일 하나만 지우면 됩니다.

  • NoriHub에서 바로 설치 hub.norideck.com에 올라온 게임팩을 앱 안에서 검색하고 한 번 클릭하면 실행됩니다.
  • 세이브는 안전하게 게임팩과 세이브 데이터가 분리되어 업데이트해도 진행 상황이 남습니다.
  • 서명과 검증 모든 게임팩은 SHA-256 해시로 검증되고, 심사를 거친 팩에는 배지가 붙습니다.
NoriHub에서 게임팩 찾기
// game.js — NoriDeck API 예시
import { deck } from 'norideck';

deck.init({ width: 240, height: 160, fps: 60 });

deck.update(() => {
  if (deck.input.pressed('A')) player.jump();
  player.step();
});

deck.draw((g) => {
  g.clear('#081419');
  g.sprite(player.sprite, player.x, player.y);
});
For Developers

게임팩 만들기

별도 엔진을 배울 필요가 없습니다. 작은 API 하나로 입력, 그래픽, 사운드, 저장을 다룹니다.

  • 240×160 픽셀 캔버스 레트로 해상도로 시작하고, 필요하면 HD 모드를 켭니다.
  • CLI 한 줄로 패키징 nori pack ./my-game
  • 핫 리로드 개발 모드 저장하면 콘솔 화면이 즉시 갱신됩니다.
