NoriDeck

.nori 카트리지를 실행하는 데스크톱 게임 콘솔입니다. 이 사이트에서 콘솔을 받고, 사용 방법과 관련 링크를 확인할 수 있습니다.

변경 내역

사용 방법

  1. 설치

    다운로드 에서 설치 파일(.exe)을 받아 실행합니다. 설치 없이 쓰려면 포터블 실행 파일을 원하는 폴더에 두고, 그 옆에 norirepo 폴더를 만들면 모든 데이터가 그 안에 저장됩니다.

  2. 카트리지 넣기

    NoriHub 에서 받은 .nori 파일을 홈 화면에 끌어다 놓거나, 파일 → 카트리지 추가로 넣습니다. 넣은 카트리지는 라이브러리에 보관되고, 열기 전에 체크섬을 검사합니다.

  3. 플레이

    홈에서 카드를 고르고(← → · 마우스 휠) Play 나 Enter. 게임 중 P 를 누르면 게임이 일시정지된 채 홈으로 나오고, 다시 P 나 카드를 누르면 이어집니다. 다른 카트리지를 실행하면 뒤에 남은 게임은 꺼집니다.

  4. 세이브 · 카트리지 관리

    카드의 톱니 메뉴(또는 오른쪽 클릭)에서 세이브 백업(zip) · 복원 · 지우기, 카트리지 내보내기, 게임 종료, 삭제를 합니다. 카트리지를 지워도 세이브는 남아 다시 넣으면 이어서 할 수 있습니다.

설정

Config 메뉴에서 언어(한국어 · English), 키 배치, 소리 크기, 배속(×1.5 ~ ×4)을 바꿉니다. 창 크기는 보기 메뉴(×0.5 · ×1 · ×1.5), 전체화면은 F11.

데이터 위치

기본은 %APPDATA%\norideck, 포터블 모드는 norirepo\. 카트리지 하나가 games\<id>\ 폴더 하나이고 세이브는 그 안의 saves\ 에 있습니다. Config 메뉴의 게임 폴더 · 데이터 폴더로 바로 열 수 있고, 폴더를 복사하면 게임과 세이브가 함께 백업됩니다.

기본 키

Config → 키 배치에서 기기 그림의 버튼 칸을 누르고 새 키를 누르면 바로 바뀝니다 (Esc 는 취소).

카트리지 만들기

카트리지는 TypeScript 로 만듭니다. NoriDeck 저장소 없이 npm create nori 로 시작하고, nori build 로 .nori 파일을 만듭니다. 기본 화면은 16:9 480×270 이며 매니페스트(nori.json)에서 정합니다.

만든 카트리지는 NoriHub 에 로그인한 뒤 등록에서 .nori 파일을 올리면 검사를 거쳐 바로 공개됩니다.

  • @nghslab/nori-sdk ↗
  • @nghslab/nori-cli ↗ 
$ npm create nori my-game
$ cd my-game
$ npx nori check
$ npx nori build
